# Elite Merchandise Traders & IT Student Portfolio

A responsive business website and student portfolio built with HTML5, CSS and JavaScript. It introduces Elite Merchandise Traders' clothing, footwear and electronics services and presents Emmanuel, the business's co-founder, as an IT student at Mulungushi University.

The contact form is a front-end demonstration: it validates and previews a message in the browser but does not send it. Add real contact details and connect a form service before using the site to receive customer enquiries.

## Sections
Business introduction, clothing/footwear/electronics service cards, co-founder story, IT student portfolio and contact form.

## Folder structure
```
index.html
css/styles.css
js/script.js
```

## Interactive features
- Contact form validation and local message preview (no message is sent).
- Light/dark theme toggle with a saved browser preference.
- Searchable IT skills cards with expandable details.

## How to test
- **Form:** submit empty, with spaces only, with `abc` as the email, then with valid data.
- **Theme:** click the Dark mode button, reload, and check the theme is kept.
- **Portfolio filter:** type `css`, then `zzz` (no match message), then press Reset. Open and close each skill card's details.
- **Phone layout:** resize the browser to about 375 px wide and check there is no sideways scrolling.
